# ReservHub

ReservHub merupakan website reservasi tempat berbasis Laravel yang menyediakan layanan reservasi untuk berbagai kategori tempat seperti Coffee Shop, Salon, dan Rental Alat.

## Role

- Admin
- Owner
- Customer

## Teknologi

- Laravel
- SQLite
- Tailwind CSS
- Vite
